# Research Findings — 001 rule enforcement

Research run 2026-10-10 by four perspectives (Technical, Requirements/UX, Security, Integration/Performance).
Sources: Claude Code docs (`https://code.claude.com/docs/en/…`, fetched 2026-10-10, v2.1.290 pages),
the mods types file `anthropics/claude-code/main/mods/types/claude-code.d.ts` (written by v2.1.277),
the installed Hookify plugin, and the web sources named per finding. Local CLI is v2.1.296.

Each finding carries a disposition: **Pending** until the user confirms, corrects, discards or defers it.
Only Confirmed or Corrected findings may enter requirements, solution or plan.

## Open questions research could not close

- `$.model.complete` return shape and options on the installed build (resolve by generating the build's types with `claude --plugin-dir`).
- Whether `agent.spawn` fires for Workflow-tool agents; coverage of out-of-process teammates.
- Whether a running background subagent keeps the session non-idle for `$.prompt.submit`.
- Whether `$.process` works outside the CLI (Desktop, VS Code, cloud).
- Whether a mod can write a sensitive `userConfig` value at runtime.
- Whether a mod's `classic.Stop` runs with no settings Stop hooks configured, and whether the 8-continuation cap applies to mod blocks (R1).
- Latency of `$.model.classify` and of inline judging — no published figures; must be measured.
