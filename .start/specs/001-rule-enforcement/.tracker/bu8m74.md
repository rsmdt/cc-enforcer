# Workflow-started agent is enforced and labelled

> Priority: P1 · Surface: technical · Verifies: FR-5 assumption

## Scenario

Setup: a fresh git repository with the cc-enforcer plugin loaded through `claude --plugin-dir <cc-enforcer>`; rule files are written as `.claude/hookify.<name>.local.md` (project) or in a temporary `HOME`'s `.claude/` (personal). Headless runs use `claude -p --output-format stream-json`, so tool results and denial reasons are visible.

Interactive session: ask Claude to run a Workflow whose agent runs `git push --force`.

## Expected

- The agent's call is denied.
- The log entry for that hit carries the agent label `workflow agent` (or the agent's name).
