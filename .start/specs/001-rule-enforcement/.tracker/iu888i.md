# Slice 2: Live rule updates

A rule file added, changed or deleted mid-session applies to the next tool call; a broken edit keeps the last good version and tells the user once.

## Features

- AC-3.1 add/change/delete applies to the next tool call
- AC-3.2 an invalid edit keeps the last valid version and the user is told

## Behavior — EARS

- WHEN a rule file is added, changed or deleted, THE SYSTEM SHALL check the next tool call against the updated rule set — AC-3.1
- IF a changed rule file fails validation, THEN THE SYSTEM SHALL keep its last valid version and tell the user once that the edit was rejected — AC-3.2

## Quality Gates

- NFR-7: a saved rule change applies to the first tool call made ≥ 2 s after the save in 100% of trials
- Baseline: concurrent events share one compile; no duplicate rejection notices
