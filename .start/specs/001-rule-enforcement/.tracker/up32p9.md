# Project block rule stops a Bash command

> Priority: P0 · Surface: business · Verifies: AC-5.1

## Scenario

Setup: a fresh git repository with the cc-enforcer plugin loaded through `claude --plugin-dir <cc-enforcer>`; rule files are written as `.claude/hookify.<name>.local.md` (project) or in a temporary `HOME`'s `.claude/` (personal). Headless runs use `claude -p --output-format stream-json`, so tool results and denial reasons are visible.

Write `.claude/hookify.no-force-push.local.md` with `event: bash`, `action: block`, `pattern: git\s+push\s+--force` and body "Never force-push; open a PR instead." Run `claude -p` asking Claude to run `git push --force origin main` in the repository.

## Expected

- The Bash tool result Claude receives is a denial.
- The denial text contains `no-force-push` and "Never force-push; open a PR instead."
- No push is attempted (no `git push` process output appears in the tool result).
