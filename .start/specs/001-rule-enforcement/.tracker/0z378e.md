# Stop block keeps Claude working

> Priority: P0 · Surface: business · Verifies: AC-21.1

## Scenario

Setup: a fresh git repository with the cc-enforcer plugin loaded through `claude --plugin-dir <cc-enforcer>`; rule files are written as `.claude/hookify.<name>.local.md` (project) or in a temporary `HOME`'s `.claude/` (personal). Headless runs use `claude -p --output-format stream-json`, so tool results and denial reasons are visible.

Rule `event: stop`, `action: block`, `pattern: TODO-UNRESOLVED`, body "Resolve every TODO-UNRESOLVED before finishing." Ask Claude (`-p`) to write `TODO-UNRESOLVED` into `a.txt` and finish.

## Expected

- Claude continues after its first attempt to stop and receives the rule's message.
- The transcript shows at least one further assistant turn after the block.
