# Overview lists rules

> Priority: P0 · Surface: business · Verifies: AC-11.1

## Scenario

Setup: a fresh git repository with the cc-enforcer plugin loaded through `claude --plugin-dir <cc-enforcer>`; rule files are written as `.claude/hookify.<name>.local.md` (project) or in a temporary `HOME`'s `.claude/` (personal). Headless runs use `claude -p --output-format stream-json`, so tool results and denial reasons are visible.

Interactive session with one project `block` rule (triggered once) and one personal `warn` rule with an evaluator. Run `/cc-enforcer-rules`.

## Expected

- Both rules appear with name, event, action, evaluator yes/no, source, on/off and hit count (1 for the triggered rule).
