# Claude reads the warning with the result

> Priority: P0 · Surface: business · Verifies: AC-8.1

## Scenario

Setup: a fresh git repository with the cc-enforcer plugin loaded through `claude --plugin-dir <cc-enforcer>`; rule files are written as `.claude/hookify.<name>.local.md` (project) or in a temporary `HOME`'s `.claude/` (personal). Headless runs use `claude -p --output-format stream-json`, so tool results and denial reasons are visible.

Rule `event: file`, default action, `pattern: console\.log\(`, body "Use the project logger." Ask Claude (`-p`, stream-json) to create `a.js` containing `console.log(1)`.

## Expected

- `a.js` is written.
- The tool result Claude receives includes `[cc-enforcer:project:<name>]` and "Use the project logger."
