# User is asked and approves

> Priority: P0 · Surface: business · Verifies: AC-6.1

## Scenario

Setup: a fresh git repository with the cc-enforcer plugin loaded through `claude --plugin-dir <cc-enforcer>`; rule files are written as `.claude/hookify.<name>.local.md` (project) or in a temporary `HOME`'s `.claude/` (personal). Headless runs use `claude -p --output-format stream-json`, so tool results and denial reasons are visible.

Interactive session, rule `event: bash`, `action: ask`, `pattern: npm\s+publish`, body "Publishing needs a release check." Ask Claude to run `npm publish --dry-run`; approve when asked.

## Expected

- A question appears naming the rule and showing its body.
- After approval the command runs.
