# Failure after the call returns the real result

> Priority: P1 · Surface: technical · Verifies: AC-9.2

## Scenario

Setup: a fresh git repository with the cc-enforcer plugin loaded through `claude --plugin-dir <cc-enforcer>`; rule files are written as `.claude/hookify.<name>.local.md` (project) or in a temporary `HOME`'s `.claude/` (personal). Headless runs use `claude -p --output-format stream-json`, so tool results and denial reasons are visible.

Build with the test fault switch that makes the after-call check throw. Ask Claude to run `echo done > f.txt`.

## Expected

- `f.txt` contains `done`.
- Claude's tool result is the command's real output, not a denial.
- The user is told the check failed.
